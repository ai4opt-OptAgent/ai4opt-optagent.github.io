NeurIPS 2025 / Modeling agents & reasoning

OptiTree: Hierarchical Thoughts Generation with Tree Search for LLM Optimization Modeling

Haoyang Liu, Jie Wang, Yuyang Cai, Xiongwei Han, Yufei Kuang, Jianye Hao

Read the paper↗Code↗Cite this work

OptiTree improves automated optimization modeling by searching a hierarchical knowledge tree for simpler subproblems and reusing their modeling strategies to guide large language models.

01 / Research question

Translating natural-language descriptions into mathematical optimization models requires correctly identifying decision variables, constraints, and objectives. Existing large language model approaches often follow a fixed sequence of modeling steps, regardless of the problem's structure or complexity. This can lead to formulation errors, particularly incorrect variable definitions in challenging problems. OptiTree investigates whether relationships among optimization problem types can support adaptive decomposition, allowing a model to build on simpler, familiar subproblems rather than formulate every complex problem from scratch.

02 / Approach

OptiTree first constructs a hierarchical modeling tree from existing optimization problems and their reference models. Each node represents a problem type and stores descriptive features and reusable modeling guidance, including variable definitions, constraints, objectives, and solver-code templates. Parent nodes represent simpler subproblems of their descendants. Given a new natural-language problem, an LLM extracts modeling-relevant statements and searches the tree from the root, selecting increasingly specific subproblems whose features match the target. The system retrieves the modeling guidance associated with the deepest matching node and combines it with the target problem's additional requirements to generate a complete formulation and solver code. During tree construction, generated solutions are checked against reference objective values, and unsuccessful cases trigger updates that incorporate new problem types or modeling patterns.

03 / Research scope

The study evaluates natural-language optimization formulation and solver-code generation on seven benchmarks, spanning elementary linear programming, integer optimization, and challenging academic and industrial problems. The main experiments use GPT-4o and DeepSeek-V3, measuring accuracy by whether the generated model's optimal objective value matches the reference value. The modeling tree is constructed from 400 OR-Instruct problems and reused at inference time, without retraining the base language model.

OptiTree outperforms the compared prompting methods on all seven benchmarks. Its gains on complex tasks suggest that searching for a familiar subproblem can provide a more useful starting point than assembling a formulation from scratch. Reusable modeling patterns let the model focus on what the target problem adds to that starting point.

Without tree search: select subproblems directly from a pool. Without modeling thoughts: retain decomposition but omit stored modeling guidance. Without statement thoughts: match subproblems using the original descriptions.

The sharpest losses on the challenging benchmarks occur when stored modeling thoughts are removed: finding a related subproblem is most useful when its modeling strategy can also be reused. The hierarchy and statement thoughts support a different part of the process, guiding the model toward the right knowledge. Together, the ablations suggest that effective reuse depends on both selecting a suitable subproblem and transferring how it is modeled.
