ICML 2026 / Verification & correction

SAC-Opt: Semantic Anchors for Iterative Correction in Optimization Modeling

Yansen Zhang, Qingcan Kang, Yujie Chen, Yufei Wang, Xiongwei Han, Tao Zhong, Mingxuan Yuan, Chen Ma

Read the paper↗Cite this work
Conceptual overview · illustrative, not an experimental result

Use semantic anchors to locate and correct mismatches between a problem and its generated model.

01 / Research question

Does executable solver code faithfully preserve the original problem semantics?

02 / Approach

Align semantic anchors from the problem with those reconstructed from code, then iteratively correct the mismatched components.

03 / Research scope

The framework investigates semantic correction without additional model training.
